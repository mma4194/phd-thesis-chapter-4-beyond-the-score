# Third-party inputs

Raw TON_IoT data are not redistributed in this repository. Obtain them from the original dataset provider and follow its terms and attribution instructions. Smart* raw files are also excluded and are not required by this Chapter 4 pipeline.

The residential Parquet is linked to the existing Chapter 3 release rather than duplicated. Its metadata and SHA-256 are in `datasets/residential/dataset.json`. A public download link does not itself specify a license. This package does not grant rights to third-party datasets or dependencies.

Python packages and system tools retain their respective licenses. Scientific source and recovered reference materials are supplied for the thesis reproduction task; select any repository software license only after confirming the author's intended permissions.
